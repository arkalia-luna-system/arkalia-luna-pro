# Rapports projet

Ce dossier conserve uniquement les rapports utiles au suivi courant.

## Politique de nettoyage

- Les rapports d'audit datés et redondants sont retirés de la racine pour limiter le bruit.
- Les informations pérennes doivent vivre dans `docs/` (architecture, sécurité, exploitation).
- Les suivis opérationnels en cours doivent rester dans des fichiers nommés explicitement par objectif.

## État actuel

Un nettoyage documentaire a été appliqué pour supprimer les rapports d'audit historiques (majoritairement datés de novembre 2025) qui faisaient doublon.
